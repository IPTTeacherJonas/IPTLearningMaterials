How Objects, Methods, this & ES6 Modules Connect

Slide 2 / 5

1. Objects, Methods & this

  • Properties: Store structured data as key: value pairs (e.g., title, author).
  • Methods: Functions defined inside an object that perform actions using that object's data.
  • The this Keyword: Dynamically points to the owner object invoking the method, avoiding hardcoded variable names.
  • Template Literals (`...`): Backtick strings allowing clean ${expression} interpolation.

2. ES6 Modular Architecture

  • Configuration (package.json): Must include "type": "module" so Node.js supports ES6 import / export.
  • Provider Module: Uses export const and export function to expose reusable components.
  • Consumer Module: Uses import { ... } from './file.js' (always including ./ and .js).

Reference Example: Library Book Tracker (Instructions Only)

Slide 3 / 5

Classroom Demonstration Protocol: No pre-written solution code is shown on this slide. Follow the specifications below while your instructor builds and runs both modules live in the VS Code Playground on the next slide.

Step 1: Provider Module (bookModule.js)

  1. Create and export an object named bookRecord containing three properties:
    • title: "Clean Code"
    • author: "Robert C. Martin"
    • year: 2008
  2. Inside bookRecord, add a method getBookLabel() that uses this and a template literal to return:
    "Clean Code" by Robert C. Martin (2008)
  3. Export a function formatBookStatus(book, status) that calls book.getBookLabel() and returns:
    Book: "Clean Code" by Robert C. Martin (2008) — Status: Available

Step 2: Consumer App (libraryApp.js)

  1. Verify package.json has "type": "module" enabled.
  2. Import bookRecord and formatBookStatus from './bookModule.js'.
  3. Invoke formatBookStatus(bookRecord, "Available") and store the returned string in a variable named message.
  4. Log message to the terminal using console.log().
  5. Execute node libraryApp.js in the integrated terminal.

Simple Written Coding Challenge: Course Enrollment Tracker

Slide 5 / 5

Directions: Using the Reference Example demonstrated by your instructor as a guide, write the complete JavaScript code for two separate files on your paper (or test your written code inside courseModule.js and enrollApp.js in the VS Code Playground).

File 1: courseModule.js (Provider)

  1. Export an object named courseDetails with these properties:
    • code: "IPT101"
    • title: "Integrative Programming"
    • units: 3
  2. Inside courseDetails, define a method getCourseHeader() using this and a template literal to return:
    "[IPT101] Integrative Programming (3 Units)"
  3. Export a function printEnrollment(course, studentName) that calls course.getCourseHeader() and returns:
    "Student <studentName> is enrolled in [IPT101] Integrative Programming (3 Units)."

File 2: enrollApp.js (Consumer)

  1. Import courseDetails and printEnrollment from './courseModule.js'.
  2. Call printEnrollment() passing courseDetails and your own full name as arguments.
  3. Print the returned string using console.log().
EXPECTED CONSOLE OUTPUT:
Student Juan Dela Cruz is enrolled in [IPT101] Integrative Programming (3 Units).
